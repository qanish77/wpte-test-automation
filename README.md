Always up to date with whatever suite last ran — pass/fail per test, and click into any test for its full step-by-step trace with screenshots and video. No download, no setup, just open the link.

## ▶️ Run a test suite (no local setup needed)

1. Go to the **[Actions tab](https://github.com/qanish77/wpte-test-automation/actions/workflows/playwright.yml)**.
2. Click **"Run workflow"**.
3. Pick a suite from the dropdown (`smoke`, `auth`, `admin`, `account`, `booking`, or `trips`).
4. Click the green **"Run workflow"** button.

Takes a few minutes. When it's done, the report link above automatically shows that run's results.
